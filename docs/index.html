Worker events

可订阅事件

需要 `events:draw` 权限。逐项事件适合每个结果执行，汇总事件适合每次操作执行一次。

Permissioned bridge

全部 RPC 与权限

核心名单、历史记录、统计和平衡信息只读；`storage.write` 只写插件自己的命名空间。

Web + Tauri

平台能力

先读取 `runtime.capabilities`。不可用的可选能力返回结构化结果，插件应提供 Web fallback 或安全跳过。

Release automation

发布与插件目录

目录不固定版本和下载 URL。宿主从 GitHub 最新正式 Release 自动解析 `.cnrp` 资源和 SHA-256。

{
  "repository": "owner/repository",
  "release": {
    "provider": "github",
    "channel": "latest",
    "assetPattern": "my-plugin-*.cnrp"
  },
  "publisherKey": "base64-spki"
}
