Two files, one identity

声明文件

身份与权限写进 manifest.yml，贡献内容写进同目录的 contributions.json；两者不能与 manifest.json 同时存在。

manifest.yml

identity · entry · permissions

反向域名 ID、名称、版本、SDK 引擎范围、入口 Worker、图标与权限清单；绝不包含 contributes / settings / pages / api。

contributions.json

settings · pages · packs

扁平贡献对象：宿主设置的 sections[].fields[]、iframe 页面、命令、动画包、视觉层、组件样式/覆盖包、原生视图与结果呈现。

integrity

cnrp pack 注入

打包时由 CLI 向 manifest.yml 注入覆盖全部包内文件的完整性清单，请勿手写。

设置归属

settings 顶层

宿主原生设置写在 contributions.json 顶层，由 VueFluentWidgets 渲染；pages[] 只承载 iframe 页面，不再使用 pages[].native。

From template to .cnrp

使用模板

仓库自带与宿主同版本的 @starcyrene/cyrene-name-roller@1.4.1 SDK，克隆后无需 registry Token 即可校验与打包。

1创建仓库使用 GitHub 的 Use this template，或直接克隆本仓库。
2修改声明改 manifest.yml 的 ID/名称/版本；贡献与设置改在 contributions.json。
3校验并打包bun install → bun run validate → bun run build，产物在 dist/*.cnrp。
bun install
bun run validate
bun run build
# -> dist/cyrene-plugin-template.cnrp

严格校验

cnrp validate 校验清单引用的每个文件；staging 还会解析页面 HTML 中的同级资源引用，防止打包后出现静默丢失的样式或脚本。

只发布载荷

打包只收录 scripts/stage-plugin.mjs 中 publishFiles 列出的文件，仓库工具、测试、CI 与 vendor SDK 不会进入 .cnrp。

Host-owned transaction

新玩法也使用宿主算法

插件提交筛选条件，宿主选出结果、增加统计并追加历史；插件不能提交候选权重、赢家 ID 或自造记录。

1插件提交条件listId、people/groups、gender、count、allowDuplicates
2宿主执行算法人员走 Core 平衡算法；小组走宿主核心选择实现。
3宿主原子提交统计与记录一并追加，写入 operationId 和 pluginId。
import { definePlugin, executeDraw, queryResource, describeHost } from '@starcyrene/cyrene-name-roller/plugin-sdk'

const receipt = await executeDraw(context, { count: 6, allowDuplicates: false })
const names = await queryResource(context, 'names')
const host = await describeHost(context)
Validated motion + isolated canvas

动画包与视觉表面

动画包适合改变宿主已有元素的呈现；Canvas/WebGL 表面适合粒子、极光和光带。两者都不会覆盖或替换真实结果。

翻牌与发牌

抽奖与全局

Canvas / WebGL

defineVisualSurface()

独立 Worker 绘制宿主内容后方的 OffscreenCanvas。

生命周期

app:theme-changed / app:resize

跟随主题、尺寸、宿主动画开关和系统 reduced motion；禁用时必须停止循环并清空动态画布。

{
  "theme": "peach | fluent | custom",
  "dark": false,
  "accent": "#D84B82",
  "perfAnimations": true,
  "reducedMotion": false
}

视觉性能合约

宿主会缓存最新主题状态，并在视觉层完成 activate 与初始 resize 后回放。

当 perfAnimations === false 或 reducedMotion === true 时，停止 interval/requestAnimationFrame、清空动态画布；恢复后检查现有句柄，只启动一个循环。

只跳过绘制但继续调度空帧不符合合约。

Freedom with a hard floor

创作自由与不可破坏的底线

插件可构建大型页面、业务流程和表现层，但权威结果与核心状态由宿主拥有。

允许

  • 添加 Dock 页面和固定插槽原生视图
  • 调用宿主事务发起新抽取
  • 声明稳定组件样式和 optional 隐藏
  • 读取名单、记录、统计、公开平衡快照
  • 扩展动画、音频、Canvas/WebGL 和平台兼容流程

不允许

  • 指定赢家、结果数组、候选权重或统计增量
  • 改写/删除既有历史和统计
  • 修改平衡算法参数或关闭公平约束
  • 隐藏权威结果、错误、完整性或恢复入口
  • 绕过 Principal、MessagePort 或安全模式访问宿主内部状态

安全模式

只能通过宿主的 safemode.json 配置启用：Tauri 修改后重启，Web 修改部署文件后重新加载。安全模式不加载任何插件包、Worker、iframe、命令、字体、动画、视觉层或 UI 贡献，插件不能自行关闭或绕过。

独立 Principal

Worker、页面、视觉层、命令与原生视图拥有独立身份；禁用、崩溃或卸载后立即撤销，不会获得宿主对象引用或内部请求 ID。

Release automation

发布与插件目录

推送 v1.2.3 格式的 tag，Release 工作流会用 Bun 校验、生成 .cnrp 并上传；目录不固定版本和下载 URL，宿主从最新正式 Release 自动解析资源与 SHA-256。

{
  "repository": "owner/repository",
  "release": {
    "provider": "github",
    "channel": "latest",
    "assetPattern": "my-plugin-*.cnrp"
  },
  "publisherKey": "base64-spki"
}
