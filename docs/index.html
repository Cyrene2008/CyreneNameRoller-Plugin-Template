Dock 一级大型页面

location: "dock" 能把完整功能放进主 Dock。页面仍通过受控桥接调用宿主能力，不会因为位置更靠前而获得额外权限。

{
  "id": "draw-studio",
  "title": "抽取实验室",
  "icon": "wand-24-regular",
  "location": "dock",
  "order": 720,
  "entry": "pages/draw-studio.html"
}

适合什么

教室座位表、全新点名玩法、课堂工具、可视化面板或其他页面级功能。

如何调用宿主

页面使用 window.CyrenePlugin.request(method, args)。主题、路由与抽取事件以只读消息发送。

如何保持一致

设置优先使用原生 schema；大型 HTML 页面参考本页 Fluent tokens，并为窄屏与深色模式设计。

Host-owned transaction

新玩法也使用宿主 CAF

插件提交筛选条件，宿主选出结果、增加统计并追加历史。插件不能提交候选权重、赢家 ID 或自造记录。

1插件提交条件listId、people/groups、gender、count、allowDuplicates
2宿主执行算法人员走 CAF；小组走宿主核心选择实现。
3宿主原子提交统计与记录一并追加，写入 operationId 和 pluginId。
const receipt = await window.CyrenePlugin.request('draw.execute', {
  target: 'people', gender: 'all', count: 6, allowDuplicates: false
})
// receipt.results 是宿主生成的只读回执
Validated motion + isolated canvas

动画包与视觉表面

动画包适合改变宿主已有元素的呈现；Canvas/WebGL 表面适合粒子、极光和光带。两者都不会覆盖或替换真实结果。

页面切换

page.transition

支持 forward/backward variants，使 Dock 路由方向正确。

结果强调

roller.finish

用受校验的 WAAPI 属性保留可读性与核心结果。

翻牌与发牌

card.deal / card.flip

分别控制卡片入场与翻面强调。

抽奖与全局

lottery.finish / global.transition

用于庆典反馈和克制的全局过渡。

Canvas / WebGL

defineVisualSurface()

独立 Worker 绘制宿主内容后方的 OffscreenCanvas。

生命周期

app:theme-changed / app:resize

跟随主题、尺寸、性能动画和 reduced motion。

Worker events

可订阅事件

抽取事件需要 events:draw，应用生命周期需要 events:lifecycle。逐项事件适合逐个反馈，汇总事件适合一次操作只执行一次。

Permissioned bridge

全部 RPC 与权限

核心名单、既有历史、统计和平衡信息只读；唯一核心追加入口是 draw.execute，storage.write 只写插件自己的命名空间。

Web + Tauri

平台能力

先读取 `runtime.capabilities`。不可用的可选能力返回结构化结果，插件应提供 Web fallback 或安全跳过。

Freedom with a hard floor

创作自由与不可破坏的底线

插件可构建大型页面、业务流程和表现层，但公平相关状态由宿主拥有。

允许

  • 添加 Dock 页面和插件子页面
  • 调用宿主 CAF 发起新抽取
  • 追加宿主生成的统计与记录事务
  • 读取名单、记录、统计、公开平衡快照
  • 扩展动画、音频、Canvas/WebGL 和平台兼容流程

不允许

  • 指定赢家、候选权重或伪造结果
  • 改写/删除既有历史和统计
  • 修改 CAF 参数或关闭公平约束
  • 覆盖真实点名/抽奖结果
  • 绕过声明权限直接访问宿主内部状态
Release automation

发布与插件目录

目录不固定版本和下载 URL。宿主从 GitHub 最新正式 Release 自动解析 `.cnrp` 资源和 SHA-256。

{
  "repository": "owner/repository",
  "release": {
    "provider": "github",
    "channel": "latest",
    "assetPattern": "my-plugin-*.cnrp"
  },
  "publisherKey": "base64-spki"
}
