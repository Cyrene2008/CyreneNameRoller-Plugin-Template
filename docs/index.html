API 1.5 host-owned UI

页面、样式、受控 DOM 与权威结果

插件只声明意图，宿主负责校验、解析和渲染。插件通过 typed groups 使用页面、样式和受控 DOM API，不会获得宿主模块、Tauri IPC 或核心算法引用。

First-level extension

Dock 一级大型页面

location: "dock" 能把完整功能放进主 Dock。页面仍通过受控桥接调用宿主能力，不会因为位置更靠前而获得额外权限。

{
  "id": "draw-studio",
  "title": "抽取实验室",
  "icon": "wand-24-regular",
  "location": "dock",
  "order": 720,
  "entry": "pages/draw-studio.html"
}

适合什么

教室座位表、全新点名玩法、课堂工具、可视化面板或其他页面级功能。

如何调用宿主

Worker 使用 SDK typed groups；页面使用宿主注入的受限 bridge。所有请求绑定当前插件 Principal 和资源所有权。

如何保持一致

设置优先使用原生 schema；大型 HTML 页面参考本页 Fluent tokens，并为窄屏与深色模式设计。

Host-owned transaction

新玩法也使用宿主 CAF

插件提交筛选条件，宿主选出结果、增加统计并追加历史。插件不能提交候选权重、赢家 ID 或自造记录。

1插件提交条件listId、people/groups、gender、count、allowDuplicates
2宿主执行算法人员走 CAF；小组走宿主核心选择实现。
3宿主原子提交统计与记录一并追加，写入 operationId 和 pluginId。
const receipt = await groups.core.operations.execute('draw', {
  target: 'people', gender: 'all', count: 6, allowDuplicates: false
})
// receipt.results 是宿主生成的只读回执
Validated motion + isolated canvas

动画包与视觉表面

动画包适合改变宿主已有元素的呈现；Canvas/WebGL 表面适合粒子、极光和光带。两者都不会覆盖或替换真实结果。

抽奖与全局

Canvas / WebGL

defineVisualSurface()

独立 Worker 绘制宿主内容后方的 OffscreenCanvas。

生命周期

app:theme-changed / app:resize

跟随主题、尺寸、宿主动画开关和系统 reduced motion；禁用时必须停止循环并清空动态画布。

{
  "theme": "peach | fluent | custom",
  "dark": false,
  "accent": "#D84B82",
  "perfAnimations": true,
  "reducedMotion": false
}

视觉性能合约

宿主会缓存最新主题状态，并在视觉层完成 activate 与初始 resize 后回放。

当 perfAnimations === false 或 reducedMotion === true 时，停止 interval/requestAnimationFrame、清空动态画布；恢复后检查现有句柄，只启动一个循环。

只跳过绘制但继续调度空帧不符合合约。

Worker events

可订阅事件

抽取事件需要 events:draw，应用生命周期需要 events:lifecycle。逐项事件适合逐个反馈，汇总事件适合一次操作只执行一次。

Permissioned bridge

接口与权限

核心名单、既有历史、统计和平衡信息只读；唯一核心追加入口是 draw.execute，storage.write 只写插件自己的命名空间。

Composable kernel

通用扩展内核

插件拥有自己的页面、命令、动画、视觉层和受限 UI 贡献；敏感状态变化通过宿主发现到的资源与事务完成。

可自由构建

Dock 页面、复杂业务页面、命令、语义主题、声明式插槽、受限样式、GSAP/WAAPI 动画、Canvas/WebGL 视觉层和插件私有存储。

pages · commands · componentStylePacks · nativeViews · resultPresentations

由宿主托管

Web Core Worker 与 Tauri Rust 权威事务负责算法、统计、记录和 Receipt。插件不能指定赢家、改写历史、修改统计或削弱公平参数。

describeHost(context) → queryResource(context, 'names') → executeTransaction(context, 'draw', input)
Web + Tauri

平台能力

先读取 `runtime.capabilities`。不可用的可选能力返回结构化结果，插件应提供 Web fallback 或安全跳过。

Freedom with a hard floor

创作自由与不可破坏的底线

插件可构建大型页面、业务流程和表现层，但权威结果与核心状态由宿主拥有。

允许

  • 添加 Dock 页面和固定插槽原生视图
  • 调用宿主 CAF 发起新抽取
  • 声明稳定组件样式和 optional 隐藏
  • 读取名单、记录、统计、公开平衡快照
  • 扩展动画、音频、Canvas/WebGL 和平台兼容流程

不允许

  • 指定赢家、结果数组、候选权重或统计增量
  • 改写/删除既有历史和统计
  • 修改 CAF 参数或关闭公平约束
  • 隐藏权威结果、错误、完整性或恢复入口
  • 绕过 Principal、MessagePort 或安全模式访问宿主内部状态
