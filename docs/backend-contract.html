Four boundaries

谁可以调用什么

公开 SDK 与内部实现严格分开。native command 名称出现在源码中，不代表插件可以直接调用。

SDK groups

public

Worker 和声明过的插件页面使用的稳定 API。方法自动生成 RPC envelope，并处理结构化错误。

JSON-RPC

cnrp-jsonrpc/1

Host 与 bundled runner/Worker 的版本化 transport。插件不应手写 envelope。

Core Worker

internal

只由宿主 CoreClient 使用。随机状态、候选集、记录和提交 envelope 不对插件开放。

Tauri commands

internal

文件、网络、runner 和 Rust core 的 native bridge。必须由宿主带入 session identity 和 grants。

Transport

统一 RPC Envelope

每个 request、response、event、cancel、heartbeat 和 shutdown 都携带协议与协商后的 API 版本。

{
  "jsonrpc": "2.0",
  "protocol": "cnrp-jsonrpc/1",
  "api": "1.5",
  "kind": "request",
  "id": "req-random-id",
  "pluginId": "cn.example.plugin",
  "instanceId": "instance-id",
  "idempotencyKey": "operation-id",
  "method": "net.request",
  "params": {}
}

Frame limits

桌面 transport 使用 4-byte little-endian length + UTF-8 JSON，单 frame 最大 1 MiB。

Binary limits

二进制只能使用 base64 chunks，每块最大 256 KiB，每个操作最大 32 MiB。

Identity

pluginId、instanceId 和 idempotency key 会在每条消息中校验。

Authenticated lifecycle

Runner / Worker 生命周期

凭据不进入 argv 或公开环境变量；host 只向插件发送规范化 metadata 与已授予 capability。

1helloHost 宣布 protocol、API、plugin 和 instance identity。
2hello.acceptedRunner 返回协商结果和 credential proof。
3initializeHost 发送 resolved capabilities，不发送 host secrets。
4readyPlugin runtime 完成初始化，开始受限 request/event 流量。

Host-owned state

Page、Window、DOM 和文件边界

插件收到 opaque IDs 和 bounded snapshots，不收到 native handles 或 host object references。

Page state

普通字段：language、theme、animation、display 和 roller.filters.*。敏感字段需要 page:write-sensitive 与 exact-patch confirmation。

Controlled DOM

只允许 query/read/write/insert。拒绝 dom.execute、raw HTML、script URL、inline handler、function source 和跨插件 node ID。

Resource quotas

每插件默认 4 windows、16 pages、32 styles、32 concurrent RPC。禁用、崩溃、unload 和 safe mode 会清理所有 handles。

File / network

路径必须位于 host-owned staged root 或声明的 external root。网络仅允许 HTTP/HTTPS，并执行 DNS、私网、redirect、size、timeout 和 concurrency 检查。

Fairness boundary

Core Operations 与 Hooks

插件只能提交 operation filters；Web Core Worker 或 Rust core 负责随机、候选、结果、记录、统计和 durable receipt。

{
  "operation": "draw",
  "filters": {
    "listId": "default",
    "target": "people",
    "count": 1,
    "gender": "all",
    "allowDuplicates": false
  }
}

Hook rules

before hooks 按 plugin load order 串行执行；后者覆盖前者的四个可变 filter 字段。

Deadlines

单 hook 最多 3 秒，整次 operation 累计最多 5 秒。

Auto-disable

10 分钟内 3 次 failure 或 5 次 explicit abort 会自动停用插件。after event 只在 commit 成功后发送。

Structured failures

错误码与处理方式

插件收到 bounded message，不会收到 stack trace、credential、native path 或 native handle。

Code含义处理
UNSUPPORTED_PLATFORM可选能力当前不可用使用 Web fallback 或安全跳过
PERMISSION_DENIED权限未授予不能靠重试解决
PENDING_CONFIRMATION需要 host confirmation使用 exact confirmation ID 重试
RESOURCE_LIMIT超出插件配额释放资源后重试
PLUGIN_INSTANCE_REVOKEDsession 已失效重新激活插件
TIMEOUT / CANCELLED请求被超时或取消非幂等操作使用新 key
CORE_INTEGRITY_FAILUREprotected state 不一致停止并进入恢复流程
PATH_OUTSIDE_ROOT / NETWORK_ADDRESS_DENIED文件或网络目标越界修正输入，不能盲目重试
Host implementation only

不要直接调用 native commands

plugin_runner_start、plugin_runner_send、plugin_files_read、plugin_net_request 和 core_prize_execute 是宿主内部实现。插件只能使用 SDK。

Host responsibilities

校验 manifest、permission、session identity、resource ownership、idempotency、limits、audit 和 cleanup。

Plugin responsibilities

在 deactivate 中释放本地资源；处理 structured errors；不缓存 host handles；不伪造 core result、random、records 或 state。
